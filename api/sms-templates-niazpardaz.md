# متن پیامک‌های سایت برای ثبت و تأیید در نیازپرداز

این فایل متن‌هایی است که باید در پنل نیازپرداز ثبت کنید تا تأیید شوند.
لحن متن‌ها گرم و محترمانه نوشته شده تا مشتری‌ها حس خوب بگیرند —
«عزیزم» و «لطفاً» و لحن خشک اداری از متن‌ها برداشته شد.

متن‌ها با خدمات تازه‌ی سایت (بن مژه، خط چشم دائم، دارک لیپس، شیدینگ و
تینت دائمی لب، میکروبلیدینگ ابرو، لیفت و لمینت) هماهنگ‌اند.

---

## چطور کار می‌کند (این را بخوانید)

نیازپرداز متد جداگانه‌ای برای «ارسال با پترن» ندارد. یعنی:

1. متن الگو را یک بار در پنل ثبت می‌کنید و منتظر تأیید می‌مانید.
2. سایت متنِ کاملِ ساخته‌شده را با متد معمولی می‌فرستد.
3. سامانه‌ی نیازپرداز آن متن را با الگوهای تأییدشده‌ی حساب شما
   تطبیق می‌دهد.

**پس متن قالب در فایل `api/config.php` باید کاراکتربه‌کاراکتر همان چیزی
باشد که تأیید شده است** — حتی فاصله، نقطه، ویرگول، دونقطه، نیم‌فاصله
و اموجی. اگر یک کاراکتر فرق کند، نیازپرداز خطای ۱۸ («مغایرت متن با قالب»)
برمی‌گرداند و پیامک نمی‌رود.

تا وقتی هر الگو تأیید نشده، مقدار همان کلید در `api/config.php` باید
`null` بماند (متن‌های آماده در همین فایل، پایین هر بخش).

> ⚠️ خط فرستنده: پیامک‌های کد تأیید و نوبت باید از **خط خدماتی** بروند،
> نه تبلیغاتی. کد تأیید (otp) از قبل تأیید شده و باید دست‌نخورده بماند.

> 🌸 **درباره‌ی اموجی گل:** در سه پیام مشتری‌محور یک گل 🌸 گذاشته‌ام که
> متن را گرم‌تر می‌کند. اگر پنل یا بازبین نیازپرداز ایراد گرفت، یا بعد از
> تأیید خطای ۱۸ گرفتید، نسخه‌ی «بدون اموجی» را در انتهای همین فایل
> بردارید و **همان** را در پنل ثبت و در `config.php` بگذارید.

## فهرست پیام‌ها

| کلید در کد | چه زمانی فرستاده می‌شود | به چه کسی |
|---|---|---|
| `otp` | هنگام ورود به سایت | مشتری |
| `received` | بلافاصله بعد از ثبت درخواست نوبت | مشتری |
| `admin_alert` | همان لحظه، همراه `received` | شماره‌های مدیر |
| `approved` | وقتی مدیر درخواست را تأیید می‌کند | مشتری |
| `rejected` | وقتی مدیر درخواست را رد می‌کند | مشتری |
| `reminder` | یادآوری روز نوبت (هنوز زمان‌بند ندارد) | مشتری |

متغیرها: `{date}` مثل «چهارشنبه ۱ مهر» · `{time}` مثل «۱۶:۳۰»
· `{service}` نام خدمت · `{name}` و `{phone}` مشخصات مشتری (فقط برای مدیر)
· `{reason}` علت رد که خودتان در پنل می‌نویسید.

## ۱) کد تأیید ورود — `otp`

**قبلاً تأیید شده؛ تغییرش ندهید.**

| | |
|---|---|
| متن ثبت‌شده | `کد تایید شما: %code%` |
| نمونه‌ی ارسالی | کد تایید شما: 1234 |
| طول | ۱۸ کاراکتر — ۱ پیامک |
| مقدار config | `'otp' => 'کد تایید شما: {code}',` (همین حالا فعال است) |

> این متن عمداً ساده و کوتاه است — پیامک کد باید سریع خوانده شود و
> بابت هر کاراکتر اضافه، هزینه‌ی پیامک دوم را هم بدهید.

---

## ۲) رسید ثبت درخواست — `received`

به مشتری می‌گوید درخواستش رسیده، برایش وقت گذاشته‌اید و به‌زودی تماس
می‌گیرید.

**متن برای ثبت در نیازپرداز (متغیرها را با فرمت پنل بنویسید):**

```
زهره زارع: درخواست %service% شما برای %date% ساعت %time% ثبت شد 🌸 به‌زودی برای تأیید تماس می‌گیریم.
```

| | |
|---|---|
| نمونه‌ی کوتاه | زهره زارع: درخواست بن مژه شما برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ ثبت شد 🌸 به‌زودی برای تأیید تماس می‌گیریم. |
| نمونه‌ی بلند | زهره زارع: درخواست دارک لیپس (روشن‌سازی لب‌های تیره) شما برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ ثبت شد 🌸 به‌زودی برای تأیید تماس می‌گیریم. |
| طول | ۹۹ تا ۱۳۷ کاراکتر — ۲ پیامک |
| مقدار config بعد از تأیید | `'received' => 'زهره زارع: درخواست {service} شما برای {date} ساعت {time} ثبت شد 🌸 به‌زودی برای تأیید تماس می‌گیریم.',` |

## ۳) خبر به سالن — `admin_alert`

به شماره‌های مدیر (`admin_phones`) می‌رود، نه به مشتری.

| | |
|---|---|
| متن برای ثبت | `زهره زارع: درخواست تازه %name% - %phone% - %service% - %date% ساعت %time%` |
| نمونه‌ی ارسالی | زهره زارع: درخواست تازه فاطمه محمدی نژاد - 09121234567 - دارک لیپس (روشن‌سازی لب‌های تیره) - چهارشنبه ۱ مهر ساعت ۱۶:۳۰ |
| طول | ۷۴ تا ۱۲۴ کاراکتر — ۲ پیامک |
| مقدار config بعد از تأیید | `'admin_alert' => 'زهره زارع: درخواست تازه {name} - {phone} - {service} - {date} ساعت {time}',` |

> این یکی عمداً «خوشگل» نشد. مخاطبش خودِ شماست و باید در یک نگاه،
> نام و شماره و خدمت و ساعت را نشان بدهد. اموجی و جمله‌ی اضافه فقط
> کاراکتر می‌خورد و متن را دوخطی می‌کند.

## ۴) تأیید نوبت — `approved`

خبر خوش؛ لحن صمیمی و دعوت‌کننده.

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: نوبت %service% شما برای %date% ساعت %time% تأیید شد 🌸 منتظر دیدن شما هستیم.
```

| | |
|---|---|
| نمونه‌ی ارسالی | زهره زارع: نوبت بن مژه شما برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ تأیید شد 🌸 منتظر دیدن شما هستیم. |
| طول | ۸۶ تا ۱۲۴ کاراکتر — ۲ پیامک |
| مقدار config بعد از تأیید | `'approved' => 'زهره زارع: نوبت {service} شما برای {date} ساعت {time} تأیید شد 🌸 منتظر دیدن شما هستیم.',` |

## ۵) رد نوبت — `rejected`

خبر خوش نیست، پس متن دلجویی‌کننده است و راه ادامه را هم نشان می‌دهد:
نام خدمت + «متأسفانه» + «علت» + شماره‌ی تماس. نام خدمت این‌جا مهم‌تر از
همه‌جاست؛ اگر مشتری چند درخواست ثبت کرده باشد، باید بداند کدام‌یکی
تأیید نشده.

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: متأسفانه نوبت %service% شما %date% ساعت %time% تأیید نشد. علت: %reason% تماس: 09178399055
```

| | |
|---|---|
| نمونه‌ی ارسالی | زهره زارع: متأسفانه نوبت بن مژه شما چهارشنبه ۱ مهر ساعت ۱۶:۳۰ تأیید نشد. علت: آن ساعت پر بود تماس: 09178399055 |
| طول | ۱۰۶ تا ۱۴۴ کاراکتر (با علت ۱۵ کاراکتری؛ کوتاه‌تر یا بلندتر شود، جابه‌جا می‌شود) — ۲ پیامک، و با نام خدمت بلند ۳ پیامک |
| مقدار config بعد از تأیید | `'rejected' => 'زهره زارع: متأسفانه نوبت {service} شما {date} ساعت {time} تأیید نشد. علت: {reason} تماس: 09178399055',` |

> پنل مدیریت اجازه نمی‌دهد درخواست بدون نوشتن «علت» رد شود، پس `{reason}`
> همیشه پر است.

**علت را چقدر بنویسم؟** جمله‌ی «علت» تنها بخشی است که خودتان می‌نویسید،
پس با کوتاه نوشتنش پیامک دو‌پیامکی می‌ماند. بیشترین طول علتی که باز هم
دو پیامکی می‌ماند، برای هر خدمت:

| خدمت | با چه علتی دو پیامکی می‌ماند |
|---|---|
| بن مژه | تا ۳۵ کاراکتر |
| خط چشم دائم | تا ۳۰ کاراکتر |
| میکروبلیدینگ ابرو | تا ۲۴ کاراکتر |
| شیدینگ و تینت دائمی لب | تا ۱۹ کاراکتر |
| لیفت و لمینت مژه و ابرو | تا ۱۸ کاراکتر |
| دارک لیپس (روشن‌سازی لب‌های تیره) | فقط تا ۸ کاراکتر — نامش ۳۳ کاراکتر است و جا را پر می‌کند؛ عملاً سه‌پیامکی |

یعنی با نام‌های بلند، علت را کوتاه بنویسید. جمله‌های کوتاه و محترمانه
کافی‌اند، مثل: «آن ساعت پر بود» · «همکارم نوبت داشت» · «مشکی بهتر است»

> اگر می‌خواهید همین «رد نوبت» هم برای دارک لیپس دو‌پیامکی بماند،
> بگویید تا «ساعت» و «شما» را از متن بردارم — با همان لحن، ولی کوتاه‌تر.
> فقط باید متن پنل و متن `config` با هم عوض شوند.

**متن برای ثبت در نیازپرداز:**

## نسخه‌ی بدون اموجی

اگر پنل، بازبین، یا خودِ خط، اموجی را قبول نکرد، **دقیقاً همین متن‌های
زیر** را در پنل و در `config.php` بگذارید. تنها فرقشان این است که جای
` 🌸` یک نقطه آمده (برداشتنِ ساده‌ی گل، جمله را بی‌نقطه و بدقلق می‌کند):

| کلید | متن بدون اموجی |
|---|---|
| `received` | زهره زارع: درخواست {service} شما برای {date} ساعت {time} ثبت شد. به‌زودی برای تأیید تماس می‌گیریم. |
| `approved` | زهره زارع: نوبت {service} شما برای {date} ساعت {time} تأیید شد. منتظر دیدن شما هستیم. |
| `reminder` | زهره زارع: یادآوری نوبت {service} شما {date} ساعت {time}. منتظر دیدن شما هستیم. |
| `rejected` | بدون تغییر (اموجی ندارد) |
| `admin_alert` | بدون تغییر (اموجی ندارد) |
| `otp` | بدون تغییر (اموجی ندارد) |

نمونه‌ی آماده برای کپی در `config.php`:

```php
'received' => 'زهره زارع: درخواست {service} شما برای {date} ساعت {time} ثبت شد. به‌زودی برای تأیید تماس می‌گیریم.',
'approved' => 'زهره زارع: نوبت {service} شما برای {date} ساعت {time} تأیید شد. منتظر دیدن شما هستیم.',
'reminder' => 'زهره زارع: یادآوری نوبت {service} شما {date} ساعت {time}. منتظر دیدن شما هستیم.',
```

## درباره‌ی طول پیامک‌ها و هزینه

عددهایی که بالا آمده با خودِ کد سایت محاسبه شده‌اند (نه تخمینی). قاعده:
پیامک فارسی هر ۷۰ کاراکتر یک پیامک حساب می‌شود و اگر متن بلندتر شد،
هر بخش بعدی ۶۷ کاراکتر است. اموجی هم هر کدام ۲ کاراکتر حساب می‌شود.

صفحه‌ی `api/sms-test.php` هم همین عددها را برای هر قالب نشان می‌دهد؛
اگر روزی متن را عوض کردید، از همان‌جا چک کنید.

| پیام | کاراکتر | پیامک |
|---|---|---|
| `otp` | ۱۸ | ۱ |
| `received` | ۹۹ تا ۱۳۷ | ۲ |
| `approved` | ۸۶ تا ۱۲۴ | ۲ |
| `reminder` | ۸۰ تا ۱۱۸ | ۲ |
| `admin_alert` | ۷۴ تا ۱۲۴ | ۲ |
| `rejected` | ۱۰۶ تا ۱۴۴ | ۲ (با نام خدمت بلند: ۳) |

عددها را با بلندترین و کوتاه‌ترین حالت واقعی حساب کرده‌ام: کوتاه‌ترین
خدمت «بن مژه» و بلندترین «دارک لیپس (روشن‌سازی لب‌های تیره)»، کوتاه‌ترین
تاریخ «جمعه ۳ دی» و بلندترین «چهارشنبه ۱۰ اردیبهشت».

> اگر خواستید هزینه پایین‌تر بیاید، کوتاه‌ترین راه این است که نام خدمت
> از `received` و `reminder` برداشته شود یا `{date}` کوتاه نوشته شود
> («چهارشنبه ۱ مهر» → «۱ مهر»). فقط بگویید؛ متن نهایی را در پنل و در
> کد یکسان می‌کنم تا خطای ۱۸ نگیرید.

## چند نکته که تأیید را راحت می‌کند

1. **نام برند اول جمله**: در همه‌ی متن‌ها «زهره زارع» اول آمده. الگویی
   که فرستنده‌اش معلوم نباشد، رد می‌شود.
2. **هیچ دو متغیری چسبیده به هم نیست** و بین‌شان کلمه‌ی ثابت هست
   (`ساعت`، `برای`، `-`). این هم شرط تأیید است.
3. **نیم‌فاصله‌ها را نگه دارید**: «به‌زودی» و «متأسفانه» و «نوبت» را
   همان‌طور که در جدول‌ها هست کپی کنید.
4. **اگر بازبین آدرس سایت خواست**، `zohrezare.ir` را به انتهای متن
   اضافه کنید و **همان متن نهایی** را در `config.php` بگذارید.
5. **بعد از تأیید هر الگو**: مقدار `null` همان کلید در `api/config.php`
   را با متن جدول عوض کنید، بعد تست بگیرید.
6. **تست با شماره‌ی خودتان**: در `api/config.php` مقدار `sms.enabled` را
   `true` کنید و این آدرس را باز کنید:
   `api/sms-test.php?tpl=approved&to=09xxxxxxxxx`
   بالای همان صفحه، فهرست همه‌ی قالب‌ها را نشان می‌دهد: متن نمونه‌ی هر
   کدام، طولش و این‌که چند پیامک حساب می‌شود. همان‌جا می‌بینید متنِ
   `config` با آنچه تأیید کرده‌اید یکی هست یا نه.
