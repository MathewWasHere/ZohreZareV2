# متن پیامک‌های سایت برای ثبت و تأیید در نیازپرداز

این فایل متن‌هایی است که باید در پنل نیازپرداز ثبت کنید تا تأیید شوند.
متن‌ها با خدمات تازه‌ی سایت (بن مژه، خط چشم دائم، دارک لیپس، شیدینگ و
تینت دائمی لب، میکروبلیدینگ ابرو، لیفت و لمینت) هماهنگ‌اند.

---

## چطور کار می‌کند (این را بخوانید)

نیازپرداز متد جداگانه‌ای برای «ارسال با پترن» ندارد. یعنی:

1. متن الگو را یک بار در پنل ثبت می‌کنید و منتظر تأیید می‌مانید.
2. سایت متنِ کاملِ ساخته‌شده را با متد معمولی می‌فرستد.
3. سامانه‌ی نیازپرداز آن متن را با الگوهای تأییدشده‌ی حساب شما
   تطبیق می‌دهد.

**پس متن قالب در فایل `api/config.php` باید کاراکتربه‌کاراکتر همان چیزی
باشد که تأیید شده است** — حتی فاصله، نقطه، ویرگول، دونقطه و نیم‌فاصله.
اگر یک کاراکتر فرق کند، نیازپرداز خطای ۱۸ («مغایرت متن با قالب») برمی‌گرداند
و اعتبار هم کم نمی‌شود ولی پیامک نمی‌رود.

تا وقتی هر الگو تأیید نشده، مقدار همان کلید در `api/config.php` باید
`null` بماند (متن‌های آماده در همین فایل، پایین هر بخش).

> ⚠️ خط فرستنده: پیامک‌های کد تأیید و نوبت باید از **خط خدماتی** بروند،
> نه تبلیغاتی. کد تأیید (otp) از قبل تأیید شده و باید دست‌نخورده بماند.

---

## فهرست پیام‌ها

| کلید در کد | چه زمانی فرستاده می‌شود | به چه کسی |
|---|---|---|
| `otp` | هنگام ورود به سایت | مشتری |
| `received` | بلافاصله بعد از ثبت درخواست نوبت | مشتری |
| `admin_alert` | همان لحظه، همراه `received` | شماره‌های مدیر |
| `approved` | وقتی مدیر درخواست را تأیید می‌کند | مشتری |
| `rejected` | وقتی مدیر درخواست را رد می‌کند | مشتری |
| `reminder` | یادآوری روز نوبت (هنوز زمان‌بند ندارد) | مشتری |

متغیرها: `{date}` مثل «چهارشنبه ۱ مهر» · `{time}` مثل «۱۶:۳۰»
· `{service}` نام خدمت · `{name}` و `{phone}` مشخصات مشتری (فقط برای مدیر)
· `{reason}` علت رد که خودتان در پنل می‌نویسید.

---

## ۱) کد تأیید ورود — `otp`

**قبلاً تأیید شده؛ تغییرش ندهید.**

| | |
|---|---|
| متن ثبت‌شده | `کد تایید شما: %code%` |
| نمونه‌ی ارسالی | کد تایید شما: 1234 |
| طول | ۱۸ کاراکتر — ۱ پیامک |
| مقدار config | `'otp' => 'کد تایید شما: {code}',` (همین حالا فعال است) |

> نکته: اگر روزی خواستید متن کد را عوض کنید، باید هم در پنل الگوی تازه
> ثبت و تأیید شود و هم همین سطر در `config.php` عوض شود.

---

## ۲) رسید ثبت درخواست — `received`

به مشتری می‌گوید درخواستش ثبت شده و منتظر تماس تأیید باشد.

**متن برای ثبت در نیازپرداز (متغیرها را با فرمت پنل بنویسید):**

```
زهره زارع: درخواست %service% برای %date% ساعت %time% ثبت شد. در انتظار تأیید.
```

| | |
|---|---|
| نمونه‌ی کوتاه | زهره زارع: درخواست بن مژه برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ ثبت شد. در انتظار تأیید. |
| نمونه‌ی بلند | زهره زارع: درخواست دارک لیپس (روشن‌سازی لب‌های تیره) برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ ثبت شد. در انتظار تأیید. |
| طول | حدود ۸۰ تا ۱۱۵ کاراکتر بسته به نام خدمت و تاریخ — ۲ پیامک |
| مقدار config بعد از تأیید | `'received' => 'زهره زارع: درخواست {service} برای {date} ساعت {time} ثبت شد. در انتظار تأیید.',` |

---

## ۳) خبر به سالن — `admin_alert`

به شماره‌های مدیر (`admin_phones`) می‌رود تا بدانند درخواست تازه آمده.

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: درخواست تازه %name% - %phone% - %service% - %date% ساعت %time%
```

| | |
|---|---|
| نمونه‌ی ارسالی | زهره زارع: درخواست تازه فاطمه محمدی نژاد - 09121234567 - دارک لیپس (روشن‌سازی لب‌های تیره) - چهارشنبه ۱ مهر ساعت ۱۶:۳۰ |
| طول | حدود ۹۰ تا ۱۲۵ کاراکتر بسته به نام مشتری و خدمت — ۲ پیامک |
| مقدار config بعد از تأیید | `'admin_alert' => 'زهره زارع: درخواست تازه {name} - {phone} - {service} - {date} ساعت {time}',` |

---

## ۴) تأیید نوبت — `approved`

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: نوبت %service% شما برای %date% ساعت %time% تأیید شد. منتظرتان هستیم.
```

| | |
|---|---|
| نمونه‌ی ارسالی | زهره زارع: نوبت بن مژه شما برای چهارشنبه ۱ مهر ساعت ۱۶:۳۰ تأیید شد. منتظرتان هستیم. |
| طول | حدود ۸۰ تا ۱۱۵ کاراکتر بسته به نام خدمت و تاریخ — ۲ پیامک |
| مقدار config بعد از تأیید | `'approved' => 'زهره زارع: نوبت {service} شما برای {date} ساعت {time} تأیید شد. منتظرتان هستیم.',` |

---

## ۵) رد نوبت — `rejected`

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: نوبت %date% ساعت %time% تأیید نشد. علت: %reason% تماس: 09178399055
```

| | |
|---|---|
| نمونه‌ی ارسالی | زهره زارع: نوبت چهارشنبه ۱ مهر ساعت ۱۶:۳۰ تأیید نشد. علت: در آن ساعت نوبت دیگری ثبت شده بود تماس: 09178399055 |
| طول | متن ثابتش ۷۴ کاراکتر است + طول علت — با علت کوتاه ۲ پیامک، با علت بلند ۳ پیامک |
| مقدار config بعد از تأیید | `'rejected' => 'زهره زارع: نوبت {date} ساعت {time} تأیید نشد. علت: {reason} تماس: 09178399055',` |

> پنل مدیریت اجازه نمی‌دهد درخواست بدون نوشتن «علت» رد شود، پس `{reason}`
> همیشه پر است. برای اینکه پیامک کوتاه‌تر بماند، علت را کوتاه بنویسید
> (مثلاً «در آن ساعت پر بود»).

---

## ۶) یادآوری نوبت — `reminder`

> ⚠️ این پیامک **هنوز در سایت سوار نشده**؛ متنش را آماده گذاشته‌ام که
> همراه بقیه تأیید شود. اگر بخواهید، بعداً یک زمان‌بند روزانه اضافه
> می‌کنم تا یک روز قبل، خودکار برود.

**متن برای ثبت در نیازپرداز:**

```
زهره زارع: یادآوری نوبت %service% شما %date% ساعت %time% است.
```

| | |
|---|---|
| نمونه‌ی کوتاه | زهره زارع: یادآوری نوبت بن مژه شما چهارشنبه ۱ مهر ساعت ۱۶:۳۰ است. |
| نمونه‌ی بلند | زهره زارع: یادآوری نوبت دارک لیپس (روشن‌سازی لب‌های تیره) شما چهارشنبه ۱ مهر ساعت ۱۶:۳۰ است. |
| طول | حدود ۶۵ تا ۹۸ کاراکتر — با نام خدمت کوتاه، تک‌پیامکی هم می‌شود |
| مقدار config بعد از تأیید | `'reminder' => 'زهره زارع: یادآوری نوبت {service} شما {date} ساعت {time} است.',` |

---

## درباره‌ی طول پیامک‌ها

عددهایی که بالا آمده با خودِ کد سایت محاسبه شده‌اند (نه تخمینی). قاعده‌ی
حساب: پیامک فارسی هر ۷۰ کاراکتر یک پیامک حساب می‌شود و اگر متن بلندتر
شد، هر بخش بعدی ۶۷ کاراکتر است. یعنی متن ۸۰ کاراکتری دو پیامک می‌شود.

- کد تأیید و (در بعضی حالت‌ها) یادآوری، تک‌پیامکی‌اند.
- رسید، تأیید و خبر به سالن دو پیامکی‌اند.
- رد نوبت با علت کوتاه دو پیامکی است؛ علت را کوتاه بنویسید تا
  سه‌پیامکی نشود.

اگر می‌خواهید پیامک‌ها ارزان‌تر تمام شوند، می‌توانم نام خدمت را از
«رسید» و «یادآوری» بردارم یا تاریخ را کوتاه کنم («۲۹ مهر» به‌جای
«چهارشنبه ۲۹ مهر») — فقط بگویید، همان را در کد و در متن الگو یکی می‌کنم.

---

## چند نکته که کار را راحت می‌کند

1. **نام برند**: در همه‌ی متن‌ها «زهره زارع» اول جمله آمده. همین باعث
   می‌شود بازبین الگو را تأیید کند (الگویی که فرستنده‌اش معلوم نباشد
   رد می‌شود).
2. **متغیر تنها نباشد**: هیچ‌جا دو متغیر چسبیده به هم نیست و بین‌شان
   کلمه‌ی ثابت هست (`ساعت`، `برای`، `-`). این هم شرط تأیید است.
3. **نیم‌فاصله‌ها را نگه دارید**: کلماتی مثل «می‌شود» و «تأیید» با
   نیم‌فاصله نوشته شده‌اند. موقع کپی‌کردن در پنل و در `config.php`
   باید همین‌طور بمانند.
4. **اگر بازبین نیازپرداز آدرس سایت خواست**، `zohrezare.ir` را به انتهای
   متن اضافه کنید و **همان متن نهایی** را در `config.php` بگذارید؛
   دوتایی باید یکی باشند.
5. **بعد از تأیید هر الگو**: مقدار `null` همان کلید در `api/config.php`
   را با متن جدول بالا عوض کنید. با یکی‌شان شروع کنید و تست بگیرید.
6. **تست بدون خرج کردن اعتبار**: در `api/config.php` مقدار
   `sms.enabled` را `true` کنید و با آدرس
   `api/sms-test.php?tpl=approved&to=09xxxxxxxxx` یک پیامک واقعی به
   شماره‌ی خودتان بفرستید. بالای همان صفحه هم فهرست همه‌ی قالب‌ها و
   متن نمونه‌شان را نشان می‌دهد.
