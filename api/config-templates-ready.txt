بخش «templates» در فایل api/config.php — نسخه‌ی آماده‌ی کپی
=================================================================

چرا این فایل هست؟
  متن هر پنج الگو در api/config.sample.php به‌صورت null است، یعنی
  «این پیامک فرستاده نشود». تا وقتی الگویی در پنل نیازپرداز تأیید
  نشده، همین null درست است.

  ولی اگر می‌خواهید متن‌ها را همین حالا بگذارید، باید دقیقاً با
  کوتیشن ساده شروع و تمام شوند. رایج‌ترین اشتباه این است که متن
  را بدون کوتیشن می‌نویسید یا از گیومه‌ی فارسی «…» استفاده می‌کنید —
  نتیجه‌اش یک خطای نگارشی در config.php است که کل سایت را از کار
  می‌اندازد و فقط پیام «سرور در دسترس نیست» را نشان می‌دهد.

  اگر این اتفاق افتاد: آدرس  https://SITE/api/health  را باز کنید؛
  شماره‌ی خط اشتباه را نشان می‌دهد.

------------------------------------------------------------------
بلوکی که باید در api/config.php جای بلوک فعلی templates بنشیند
(فقط بخش «templates» را عوض کنید، نه کل فایل):

        'templates' => [
            'otp'         => 'کد تایید شما: {code}',
            'received'    => 'درخواست {service} شما برای {date} ساعت {time} ثبت شد! به‌زودی برای تأیید تماس می‌گیریم.',
            'admin_alert' => 'درخواست جدید! {name} - {phone} - {service} - {date} ساعت {time}',
            'approved'    => 'نوبت {service} شما برای {date} ساعت {time} تأیید شد. راس ساعت مقرر می‌بینتون!',
            'rejected'    => 'متأسفانه نوبت {service} شما {date} ساعت {time} تأیید نشد. علت: {reason} تماس: 09178399055',
            'reminder'    => 'یادآوری نوبت {service} شما {date} ساعت {time} منتظر دیدن شما هستیم.',
        ],
------------------------------------------------------------------

نکته‌های مهم:
  • هر مقدار باید بین دو کوتیشن ساده باشد و آخرش ویرگول داشته باشد.
  • این متن‌ها باید کاراکتر‌به‌کاراکتر با الگوی تأییدشده‌ی نیازپرداز
    یکی باشند، وگرنه خطای ۱۸ می‌گیرید. رونوشت آماده‌ی پنل در
    api/sms-templates-niazpardaz.md است.
  • تا وقتی الگویی در پنل تأیید نشده، همان کلید را null بگذارید.
  • 'enabled' => true فقط بعد از یک ارسال واقعیِ موفق. اگر true باشد
    و ارسال رد شود، هیچ‌کس نمی‌تواند وارد سایت شود.
  • اگر تعداد کاراکترها را می‌خواهید: هر پیامک فارسی ۷۰ کاراکتر است.
